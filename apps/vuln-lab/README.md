# apps/vuln-lab

Intentionally vulnerable local-business (café) site, for the user's own self-study
penetration-testing practice. **Localhost only — never build, deploy, or expose this app.**
Full details, including the list of intentional vulnerability categories: see
[CLAUDE.md](CLAUDE.md).

## Quick start

```bash
pnpm --filter vuln-lab dev
```

Then open `http://localhost:3100`.
